# Hackathon

O ponto de entrada para a banca é o [README raiz](../README.md), com demo, execução local, guia de evidências e limitações. Este diretório reúne o código do frontend, backend, serviço `ai`, dados, testes, ferramentas e infraestrutura do CapiWatt Lens.

[Ambiente AWS — serviços disponíveis](docs/Ambiente%20AWS%20-%20serviços%20disponíveis.md) registra as permissões do hackathon (decisão de Eduardo, 2026-09-20). A [ADR-0002](docs/adr/0002-implantacao-aws-ecs-fargate-cdk.md) descreve a arquitetura de implantação posterior ao primeiro ciclo local. O [Compose](docker-compose.yml) continua sendo a forma de executar a demonstração local, com embeddings falsos e prévia de e-mail por padrão.
